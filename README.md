# Tactical-Projectile-Systems


A Venice Unleashed (VU) mod that adds tactical projectile systems, including grenade and smoke launch capabilities, with Coherent Gameface integration for the user interface.

Features

💥 Launch explosive grenades

🌫️ Deploy smoke grenades

🎯 Dedicated projectile launch functionality

🖥️ Coherent Gameface powered UI

⚙️ Configurable and expandable projectile systems

🔧 Designed for Venice Unleashed servers

Overview

Tactical-Projectile-Systems expands the tactical equipment available in Venice Unleashed by providing systems for launching different types of projectiles.

The mod uses Coherent Gameface for its UI, allowing the projectile system to provide an interactive and modern in-game interface.

The project is designed with flexibility in mind, making it possible to add additional projectile types, UI elements, and gameplay functionality in future updates.

Coherent Gameface

The user interface is built using Coherent Gameface, the UI framework used by modern Venice Unleashed modding.

For information about migrating and working with Gameface, see the official VU documentation:

Gameface Migration Guide:
https://docs.veniceunleashed.net/modding/gameface-migration/

Gameface can be used by the mod to provide UI functionality such as:

Projectile selection

Launcher status

Ammunition information

Smoke/grenade selection

Tactical controls

Configuration menus

Future launcher-related UI features

Supported Projectiles
Projectile	Description
💥 Grenade	Launches an explosive grenade
🌫️ Smoke	Deploys a smoke screen
Installation

Download or clone this repository.

Place the mod files in your VU server/mod directory.

Ensure the required Gameface UI files are included.

Configure the mod as required.

Start your VU server.

Verify that Tactical-Projectile-Systems and its Gameface UI load correctly.

Installation paths may vary depending on your Venice Unleashed server configuration.
